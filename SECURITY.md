# Security Policy

Midnight Rift Run is a static browser game. It does not use credentials, API keys, authentication, analytics, cookies, a database, or server-side code.

## Reporting

Please open a GitHub issue for normal bugs. If you find something that looks sensitive, avoid posting secrets or private data in the issue body and contact the repository owner directly through GitHub first.

## Local Files

The repository intentionally ignores local configuration and generated files such as `.env`, `.env.*`, `.idea/`, `node_modules/`, `dist/`, and `build/`.
